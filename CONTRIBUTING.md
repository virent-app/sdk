# Contributing

This repository is the public publishing mirror for `@virent.app/sdk`.

Virent maintains SDK source in the private product monorepo and generates this repository for npm Trusted Publishing, provenance, and package auditability. Please do not open pull requests that edit SDK source directly in this repository.

For bugs, support, or security-sensitive reports, email virent.app@gmail.com. Virent maintainers will make accepted changes in the source monorepo and publish them back to this mirror.
